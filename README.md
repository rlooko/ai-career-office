# My AI Career Office (MVP)

Mac M2에서 Ollama를 이용하는 로컬 멀티 에이전트 구조의 첫 버전입니다. 현재는 총괄 비서와 학습 코치 2개 역할을 **하나의 로컬 모델에 순차적으로 호출**합니다. 채용공고 자동 수집, 캘린더 연동, 자동 알림, GitHub/Tistory 발행은 아직 구현되지 않았습니다.

## 실행

1. Ollama 설치 후 `ollama pull qwen3:4b` 실행
2. 터미널에서 이 폴더로 이동: `cd ~/my-ai-career-office`
3. `python3 main.py` 실행 (Python 3.9+ 권장)
4. 메뉴 `1`로 아침 브리핑 생성, `2`로 업무 등록, `3`으로 업무 확인, `4`로 완료 표시

별도 pip 패키지가 필요하지 않습니다. Ollama가 로컬 `http://localhost:11434`에서 실행 중이어야 합니다.
